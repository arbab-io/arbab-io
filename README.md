### The work I find most interesting

The seam between JavaScript and native. Live Activities that survive app termination,
background timers that stay accurate when the OS deprioritizes you, screen capture
prevention, DRM-protected playback, HealthKit sync that behaves offline. When no React
Native library exists for something, I write the bridge.

Alongside that: subscription infrastructure. Receipt validation, sandbox testing quirks,
and the gap between what client-side billing APIs report and what's actually true on the
server. Getting paywalls right is less glamorous than it is load-bearing.
