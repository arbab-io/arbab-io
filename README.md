## Open source

### `react-native-football-formation`

[![npm](https://img.shields.io/npm/v/react-native-football-formation?style=flat-square&color=CB3837&logo=npm)](https://www.npmjs.com/package/react-native-football-formation)
[![license](https://img.shields.io/npm/l/react-native-football-formation?style=flat-square&color=blue)](https://github.com/arbab-io/react-native-football-formation/blob/main/LICENSE)
[![stars](https://img.shields.io/github/stars/arbab-io/react-native-football-formation?style=flat-square&color=yellow)](https://github.com/arbab-io/react-native-football-formation)

A customizable component for rendering football team formations with player positions,
stats, and match information. All 24 major tactical formations, full TypeScript
definitions, themeable at every layer, and zero dependencies beyond React Native core.

Built for sports apps, fantasy platforms, and tactical analysis tools.

```bash
npm install react-native-football-formation
```

## What I find most interesting

The seam between JavaScript and native. Live Activities that survive app termination,
background timers that stay accurate when the OS deprioritizes you, screen capture
prevention, DRM-protected playback, HealthKit sync that behaves offline. When no React
Native library exists for something, I write the bridge.

Alongside that: subscription infrastructure. Receipt validation, sandbox testing quirks,
and the gap between what client-side billing APIs report and what is actually true on the
server. Getting paywalls right is less glamorous than it is load-bearing.
